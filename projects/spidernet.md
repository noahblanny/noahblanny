# SpiderNet — Network Inventory

[← Back to portfolio](../README.md)

## Overview
Python and SQLite network inventory project designed to discover local devices and record IP addresses, MAC addresses, hostnames, and status.

## What this demonstrates
Device discovery and tracking; database-backed inventory; identification of known versus unknown devices.
